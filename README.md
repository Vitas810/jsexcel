# JS Excel

SPA-проект таблицы в стиле Excel на чистом JavaScript.

## Демо

[https://vitas810.github.io/jsexcel/](https://vitas810.github.io/jsexcel/)

## Что реализовано

- редактирование ячеек и формул;
- выделение диапазонов и применение стилей;
- изменение размеров строк и колонок;
- сохранение таблиц в `localStorage`;
- дашборд со списком сохраненных таблиц.

## Запуск проекта

```bash
npm install
npm run start
```

Приложение будет доступно по адресу `http://localhost:3000`.

## Полезные команды

- `npm run test` — запуск unit-тестов (Jest);
- `npm run lint` — проверка кода ESLint;
- `npm run build` — production-сборка в `dist`.
